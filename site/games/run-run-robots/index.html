Run Run Robots

Run. Be run after. Laugh.

Climb from the bunker toward the road beyond. Watch the searchlights, throw the breakers to restore power, and keep out of the robots' reach.

Play Run Run Robots ↗ Download HTML

One self-contained HTML file, with desktop and phone controls.

Controls

Move quietly. Keep going.

Throw every breaker to power the way out. Standing at a breaker throws it; getting there is the hard part.

Desktop
WASD or arrow keys move. Click or drag to steer. Hold Shift or toggle SNEAK to move quietly. R restarts the floor and M toggles sound.
Phone or tablet
Touch or drag to steer. Stand at a breaker to throw it. Use the SNEAK button to change movement mode.

Escape guide

Light and noise matter.

Robots patrol, investigate noise, and give chase when they see you. Searchlights can raise the alarm on the surface.

  • Sneak when a robot is nearby.
  • Use grates and machinery to make an escape route.
  • Watch the power display to track the remaining breakers.
